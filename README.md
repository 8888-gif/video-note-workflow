# B站视频转图文笔记工作流

这是一套面向学习复盘的 Windows 工具和教程包，用来把 B 站课程视频整理成可复习、可分享的图文并茂笔记。

## 它能做什么

| 功能 | 说明 |
|---|---|
| 批量下载 B 站视频 | 一行一个链接，支持合集/分 P |
| 自动合并音视频 | 使用 FFmpeg 把分离的视频流和音频流合并为 `.mp4` |
| 批量上传百度网盘 | 支持全选下载目录视频，复制到百度网盘同步目录 |
| 支持视频信息提取流程 | 上传后可配合百度网盘会员能力提取摘要、字幕、关键帧 |
| 输出图文笔记 | 提供 Markdown 模板，适合整理操作步骤、参数表格和图片清单 |
| 朋友圈分享 PPT | 提供一份可编辑 PPT，用于介绍这套流程 |

## 文件说明

| 文件 | 用途 |
|---|---|
| `启动B站批量下载器.cmd` | 双击打开图形界面 |
| `安装依赖.ps1` | 首次使用时安装/检查 yt-dlp 和 FFmpeg |
| `BilibiliDownloaderUI.ps1` | 图形界面主程序 |
| `download_bilibili.ps1` | 批量下载脚本 |
| `合并已下载音视频.ps1` | 合并旧的音视频分离文件 |
| `使用说明.md` | 工具使用说明 |
| `视频转图文笔记_分享版流程.md` | 完整工作流教程 |
| `图文笔记模板.md` | Markdown 笔记模板 |
| `B站视频转图文笔记工作流_朋友圈分享版.pptx` | 朋友圈/社群分享用 PPT |
| `urls.example.txt` | 链接文件示例，首次使用可复制为 `urls.txt` |

## 推荐流程

1. 首次使用时运行 `安装依赖.ps1`。
2. 打开 `启动B站批量下载器.cmd`。
3. 收集 B 站课程链接，一行一个。
4. 粘贴链接并点击 `开始下载`。
5. 如有音视频分离，点击 `合并已下载音视频`。
6. 点击 `全选下载视频`。
7. 选择百度网盘同步目录，点击 `批量上传到同步目录`。
8. 在百度网盘中使用会员功能提取视频摘要、字幕、关键帧。
9. 使用 `图文笔记模板.md` 整理成 Markdown 笔记。

## 不建议上传到 GitHub 的内容

| 内容 | 原因 |
|---|---|
| `downloads/` | 视频文件体积大，且可能涉及版权 |
| `cookies.txt` | 包含个人登录信息 |
| `urls.txt` | 可能包含个人链接参数或学习记录 |
| `BaiduUploadQueue/` | 本地上传队列，不属于教程源码 |

## 重要说明

请只处理你有权下载、保存、整理和分享的内容，例如自己的视频、公开授权课程、个人学习资料或已获得许可的内容。不要用于绕过付费、会员、版权或平台访问限制。
